# ChatGPT Gateway for Home Assistant

A Home Assistant app that signs in to your ChatGPT plan with OpenAI's official Sign in with ChatGPT
and offers its models on your home network as an OpenAI-compatible API, for
[FlowPilot](https://github.com/darkdarin/flowpilot) and other local clients.

Work in progress: see [AGENTS.md](AGENTS.md).
